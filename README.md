# Today Cat

Уютный план с пиксельным котёнком. Первый запуск — знакомство без почты и пароля: котёнок спрашивает, для чего нужен трекер, и сразу открывает привычки, рабочий планер или фокус дня. Режим запоминается в этом браузере.

Задачи, привычки и отметки лежат в `localStorage` под ключом `today-cat.notebook.v1`. Если в браузере ещё есть старый список `today-cat.tasks.v1`, он переносится в блокнот и остаётся на месте. Синхронизация между устройствами — отдельный этап, экран входа сейчас не показывается.

## Требования

- Node.js 20 или новее
- npm

## Локальный запуск

Приложение открывается без переменных окружения: данные не уходят с этого браузера.

```bash
npm install
npm run dev
```

Приложение открывается на [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Проверки и сборка

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

Собранная версия открывается на [http://127.0.0.1:4173](http://127.0.0.1:4173). Каталог сборки — `dist`. Картинки из `public/` попадают в корень `dist` и доступны по тем же путям, что и в разработке: `/mascot/cat-working.png`, `/mascot/cat-success.png`, `/mascot/cat-sleeping.png`.

## Изображения котёнка

Оригиналы лежат в `assets-original/`. В интерфейсе используются файлы из `public/mascot/`:

- `cat-wave.png` — котёнок машет лапкой на первом экране
- `cat-working.png` — есть незакрытые задачи
- `cat-success.png` — короткая реакция на выполнение
- `cat-sleeping.png` — открытых задач нет

## Публикация на Vercel

В репозитории есть `vercel.json`: сборка `npm run build`, каталог `dist`, фреймворк Vite. Функции `api/auth`, `api/profile` и `api/tasks` собираются в CommonJS и читают секреты только на сервере.

Текущий интерфейс не требует `DATABASE_URL` и почтовых ключей. Серверные функции в `api/` остаются в репозитории для будущего этапа синхронизации.

Продакшен публикует ветку `main`: [https://tyeldxmi-seven.vercel.app](https://tyeldxmi-seven.vercel.app).
