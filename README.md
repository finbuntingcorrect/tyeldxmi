# Today Cat

Уютный список задач на сегодня с пиксельным котёнком. Данные остаются в `localStorage` этого браузера.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:5173](http://127.0.0.1:5173).

Проверка типов и сборка:

```bash
npm run typecheck
npm run build
npm run preview
```

Собранная версия доступна на [http://127.0.0.1:4173](http://127.0.0.1:4173).
