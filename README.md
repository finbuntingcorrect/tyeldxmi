# Today Cat

Уютный список задач на сегодня с пиксельным котёнком. Это статическое приложение: без регистрации, без сервера и без внешних API. Задачи записываются в `localStorage` браузера под ключом `today-cat.tasks.v1`.

На сегодня показываются только задачи локальной даты. Незавершённые дела прошлых дней остаются в хранилище и переносятся на сегодня только по кнопке «Перенести».

## Требования

- Node.js 20 или новее
- npm

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение открывается на [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Проверки и сборка

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

Собранная версия открывается на [http://127.0.0.1:4173](http://127.0.0.1:4173). Каталог сборки — `dist`. Картинки из `public/` попадают в корень `dist` и доступны по тем же путям, что и в разработке: `/mascot/cat-working.png`, `/mascot/cat-success.png`, `/mascot/cat-sleeping.png`.

## Изображения котёнка

Оригиналы лежат в `assets-original/`. В интерфейсе используются файлы из `public/mascot/`:

- `cat-working.png` — есть незакрытые задачи
- `cat-success.png` — короткая реакция на выполнение
- `cat-sleeping.png` — открытых задач нет

## Публикация на Vercel

В репозитории уже есть `vercel.json`: сборка `npm run build`, каталог `dist`, фреймворк Vite. Отдельных переменных окружения нет.

Приложение — одна страница по адресу `/`. Состояние задач живёт в браузере посетителя, поэтому `localStorage` в production работает так же, как после `npm run preview`.

Репозиторий: [finbuntingcorrect/tyeldxmi](https://github.com/finbuntingcorrect/tyeldxmi). Код приложения находится в ветке с пул-реквестом, а не только в `main`. Vercel по умолчанию публикует ветку `main`, поэтому перед деплоем эту ветку нужно влить в `main` либо явно выбрать её в настройках проекта.

Публикация с этой машины не выполнялась: Vercel CLI не авторизован.
