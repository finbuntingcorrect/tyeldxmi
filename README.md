# Today Cat

Уютный список задач на сегодня с пиксельным котёнком. Регистрации нет: список один на всех, кто открывает сайт. Задачи лежат в Neon Postgres. Браузер ходит только в `/api/tasks`, а строка подключения читается на сервере из `DATABASE_URL`.

Если в этом браузере ещё остались задачи под ключом `today-cat.tasks.v1`, они один раз копируются в базу и после этого удаляются из браузера.

На сегодня показываются только задачи локальной даты. Незавершённые дела прошлых дней остаются в базе и переносятся на сегодня только по кнопке «Перенести».

## Требования

- Node.js 20 или новее
- npm

## Локальный запуск

Для серверных запросов нужна переменная `DATABASE_URL`. Её можно положить в локальный `.env` — этот файл не коммитится. В клиентский код она не попадает.

```bash
npm install
npm run dev
```

Приложение открывается на [http://127.0.0.1:5173](http://127.0.0.1:5173). В этом режиме `/api/tasks` обслуживает сам Vite.

## Проверки и сборка

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

Собранная версия открывается на [http://127.0.0.1:4173](http://127.0.0.1:4173). Каталог сборки — `dist`. Картинки из `public/` попадают в корень `dist` и доступны по тем же путям, что и в разработке: `/mascot/cat-working.png`, `/mascot/cat-success.png`, `/mascot/cat-sleeping.png`.

## Изображения котёнка

Оригиналы лежат в `assets-original/`. В интерфейсе используются файлы из `public/mascot/`:

- `cat-working.png` — есть незакрытые задачи
- `cat-success.png` — короткая реакция на выполнение
- `cat-sleeping.png` — открытых задач нет

## Публикация на Vercel

В репозитории есть `vercel.json`: сборка `npm run build`, каталог `dist`, фреймворк Vite. Функции лежат в `api/` и в production читают `DATABASE_URL` из настроек проекта Vercel. Значение не записывается в репозиторий и не отдаётся в браузер. Сборка упаковывает эти функции в один файл, чтобы Vercel мог их запустить.

Продакшен публикует ветку `main`: [https://tyeldxmi-seven.vercel.app](https://tyeldxmi-seven.vercel.app).
